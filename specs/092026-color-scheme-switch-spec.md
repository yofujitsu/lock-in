# Задание: система тем и панель «Стиль» для тренажёра слепой печати (Lock In)

## Цель

Добавить в приложение настраиваемое оформление:

1. Несколько цветовых палитр, у каждой есть тёмная и светлая версия.
2. Выбор шрифта интерфейса и шрифта набираемого текста.
3. Переключатель тёмной и светлой темы.
4. Размер набираемого текста.
5. Выбор того, как показывать ошибки при наборе.
6. Всё это живёт в выпадающей панели «Стиль». Панель открывается отдельной кнопкой в шапке и не висит на экране постоянно.

Выбор пользователя сохраняется и восстанавливается при следующем запуске.

Ориентир по поведению и внешнему виду: интерактивный прототип https://claude.ai/artifact/9URQNDe19pdn2xqm4KU8n2 (панель «Стиль прототипа» вверху, ниже сам тренажёр). Если ссылка недоступна, ориентируйтесь на описание ниже.

> Стек не указан. Сначала изучите текущий код (фреймворк, способ стилизации, где лежит шапка, где хранятся настройки) и встройте функциональность в существующую архитектуру. Не переписывайте то, что не относится к задаче.

## 1. Дизайн-токены

Весь цвет в приложении должен идти только через CSS-переменные ниже. Жёстко прописанные цвета в компонентах нужно заменить на токены.

| Токен | Назначение |
|---|---|
| `--bg` | фон страницы |
| `--card` | фон карточек, панелей, кнопок, поля набора |
| `--line` | рамки, разделители, фон «дорожки» сегментированных переключателей |
| `--untyped` | ещё не набранный текст |
| `--typed` | верно набранный текст и основной текст интерфейса |
| `--accent` | каретка, активный переключатель, акценты в статистике и профиле |
| `--err` | цвет ошибки |
| `--on-accent` | цвет текста поверх заливки `--accent` |
| `--font-ui` | шрифт интерфейса |
| `--font-text` | шрифт набираемого текста |
| `--text-size` | размер набираемого текста (px) |

Производные значения считаются от токенов, отдельно их хранить не нужно:

```css
--muted: color-mix(in srgb, var(--typed) 55%, var(--bg)); /* подписи, второстепенный текст */
```

Общие правила:

- Не использовать чистый чёрный `#000` и чистый белый `#FFF` для текста и фона (для карточек в светлой теме допустим `#FFFFFF`, он уже заложен в палитры).
- Акцент использовать только для каретки, активных переключателей, статистики и небольших акцентов. Больших цветных заливок избегать.
- Смена палитры и темы должна происходить плавно: `transition: background .25s, color .25s, border-color .25s` на основных поверхностях.

## 3. Шрифты

Все шрифты обязательно с кириллицей, потому что в приложении есть режим RU.

- **Шрифт интерфейса** (выбор из 5): Onest, Manrope, Nunito, Golos Text, Inter.
- **Шрифт текста** (выбор из 4, только моноширинные): IBM Plex Mono, JetBrains Mono, Fira Mono, Roboto Mono.

Правила:

- При выборе палитры автоматически подставляется её пара шрифтов из раздела 2. После этого пользователь может поменять любой шрифт вручную, и его выбор остаётся, пока он не выберет другую палитру.
- Начертания: 400, 500, 600 (для интерфейса можно добавить 700 у Manrope и Nunito). Для моно достаточно 400 и 500.
- Подключение: по возможности разместить файлы шрифтов локально (self-host, формат woff2, подмножества `latin` и `cyrillic`). Если это существенно усложняет сборку, допустимо подключение через Google Fonts с `display=swap`.
- У каждого шрифта должен быть fallback: для интерфейса `system-ui, sans-serif`, для текста `ui-monospace, monospace`.
- Для набираемого текста использовать обычное начертание (400), межстрочный интервал около 1.8.

## 4. Размер текста

- Ползунок от 20 до 38 px, шаг 1, значение по умолчанию 28 px.
- Значение рядом с ползунком показывается в виде `28px`.
- Применяется к блоку с набираемым текстом через `--text-size`. На узких экранах размер ограничивается: `font-size: min(var(--text-size), 5.6vw)`.
- Высота поля набора равна пяти строкам: `height: calc(font-size * 1.8 * 5)`. Изменение размера не должно ломать прокрутку за кареткой: после смены размера пересчитать положение каретки.

## 5. Как показывать ошибки

Три режима, переключатель-сегмент «Заметные / Мягкие / Подчёркивание». По умолчанию «Заметные».

| Режим | Что видит пользователь |
|---|---|
| **Заметные** (`strong`) | цвет буквы `--err` и полупрозрачный фон под ней: `color-mix(in srgb, var(--err) 16%, transparent)`, скругление 4px |
| **Мягкие** (`soft`) | без фона, цвет буквы приглушён: `color-mix(in srgb, var(--err) 72%, var(--untyped))` |
| **Подчёркивание** (`line`) | буква остаётся цвета `--typed`, под ней сплошная линия `--err` толщиной 2px, `text-underline-offset: 6px` |

Реализация: атрибут `data-err="strong|soft|line"` на `<html>` и CSS:

```css
.char.wrong { color: var(--err); background: color-mix(in srgb, var(--err) 16%, transparent); border-radius: 4px; }
[data-err="soft"] .char.wrong { background: none; color: color-mix(in srgb, var(--err) 72%, var(--untyped)); }
[data-err="line"] .char.wrong { background: none; color: var(--typed); text-decoration: underline; text-decoration-thickness: 2px; text-decoration-color: var(--err); text-underline-offset: 6px; }
```

(Имена классов `.char.wrong` подставьте из существующего кода.)

Дополнительно:

- Пропущенные по Tab символы остаются цветом `--untyped` с тонким подчёркиванием `color-mix(in srgb, var(--err) 60%, transparent)`.
- Каретка: линия шириной 2px цвета `--accent`, мигает, но не мигает пока пользователь не начал печатать. При `prefers-reduced-motion: reduce` мигание отключается.

## 6. Панель «Стиль»

### Кнопка

- В шапке, справа, рядом с кнопкой «New text» и существующей кнопкой солнце/луна. Кнопка квадратная, того же вида, что соседние (иконка-кнопка 44×44, рамка `--line`, фон `--card`, иконка цвета `--muted`).
- Иконка: палитра, кисть или «Aa» (на выбор). Подпись для скринридеров: «Настройки стиля». Атрибуты `aria-expanded` и `aria-controls`.
- Пока панель открыта, кнопка в подсвеченном состоянии (рамка `--accent`).
- Существующую кнопку быстрого переключения темы оставить, она должна синхронизироваться с переключателем в панели.

### Поведение панели

- По умолчанию скрыта. Открывается и закрывается по клику на кнопку.
- Закрывается по клику вне панели и по клавише `Esc`. После закрытия по `Esc` фокус возвращается на кнопку.
- На десктопе это поповер, прикреплённый к кнопке (выпадает вниз и вправо, выравнивание по правому краю кнопки), ширина около 420–460 px, скругление 18px, рамка `--line`, фон `--card`, лёгкая тень.
- На узких экранах (до 640 px) панель раскрывается как нижний лист (bottom sheet) на всю ширину с максимальной высотой примерно 80% экрана и прокруткой внутри.
- Изменения применяются сразу, без кнопки «Применить». Панель не закрывается при изменении настроек, чтобы можно было подобрать сочетание.
- Пока панель открыта, ввод в поле набора не должен перехватывать нажатия клавиш. Фокус на элементах панели не должен вызывать ввод символов в тренажёр. После закрытия панели фокус возвращается в поле набора (или на кнопку, если панель закрыта через `Esc`).
- Открытие панели не должно сбрасывать текущий тест и статистику.

### Содержимое панели (сверху вниз)

1. **Палитра**: сетка карточек (2 колонки в поповере). В каждой карточке название, ряд из 6 кружков-образцов (`bg`, `card`, `untyped`, `typed`, `accent`, `err` текущей темы) и короткое описание. Выбранная карточка с рамкой `--accent`. Образцы всегда показывают цвета для текущей выбранной темы (тёмной или светлой).
2. **Тема**: сегмент «Тёмная / Светлая».
3. **Шрифт интерфейса**: выпадающий список (`<select>` или аналог). Названия в списке желательно отображать самим шрифтом.
4. **Шрифт текста**: выпадающий список.
5. **Размер текста**: ползунок и значение в px.
6. **Как показывать ошибки**: сегмент из трёх режимов и одна строка-подсказка под ним: «Введите неверную букву, чтобы увидеть, как это выглядит».
7. Внизу ссылка-кнопка «Сбросить стиль», возвращает настройки к значениям по умолчанию (Dusk, тема по системе, пара шрифтов Dusk, размер 28, ошибки «Заметные»).

Все подписи, названия палитр и режимов оформить в едином стиле с остальным приложением. Подписи полей писать обычным регистром, без капса.

## 7. Хранение и загрузка

- Ключ в `localStorage`, например `lockin-style`. Формат JSON: `{ "palette": "dusk", "theme": "dark", "uiFont": "Onest", "textFont": "IBM Plex Mono", "size": 28, "err": "strong" }`.
- Все чтения и записи в `try/catch`. Если данных нет, они повреждены или неизвестная палитра, используются значения по умолчанию.
- Если пользователь ещё ничего не выбирал, тема определяется через `prefers-color-scheme`. Как только он выбрал тему вручную, дальше используется его выбор.
- Если в приложении уже есть профиль или синхронизация настроек с сервером, положить стиль вместе с остальными настройками. Иначе достаточно `localStorage`.
- **Без мигания при загрузке:** применить сохранённые токены до первого рендера (небольшой inline-скрипт в `<head>` или SSR), чтобы не было вспышки неправильной темы.

## 8. Доступность

- Все контролы панели доступны с клавиатуры (Tab, стрелки в сегментах, Enter/Space).
- Видимый фокус у всех интерактивных элементов (обводка цветом `--accent`).
- Панель имеет `role="dialog"` (или поповер-паттерн, принятый в проекте) и понятное имя «Настройки стиля».
- Выбранное состояние в сегментах и карточках палитр передавать через `aria-pressed` или `aria-checked`, а не только цветом.
- Красный не должен быть единственным признаком ошибки. В режиме «Мягкие» проверить, что ошибка всё равно заметна: при необходимости чуть увеличить долю `--err` в формуле.

## 9. Критерии приёмки

- [ ] В шапке есть кнопка «Стиль», по клику открывается панель, по клику вне панели и по `Esc` закрывается.
- [ ] Панель содержит: выбор палитры (5 штук), тему, шрифт интерфейса, шрифт текста, размер текста, режим ошибок, сброс.
- [ ] Все 5 палитр работают в обеих темах. Цвета совпадают с таблицами выше.
- [ ] Выбор палитры подставляет её пару шрифтов, ручной выбор шрифта после этого сохраняется.
- [ ] Все шрифты корректно отображают кириллицу (проверить режим RU).
- [ ] Изменение любой настройки применяется мгновенно, без перезагрузки и без сброса текущего теста.
- [ ] Три режима ошибок отображаются как описано, в том числе во всех палитрах.
- [ ] Настройки сохраняются и восстанавливаются после перезагрузки страницы, при первой загрузке нет вспышки неправильной темы.
- [ ] Нажатия клавиш в панели не попадают в тренажёр, после закрытия панели набор продолжается.
- [ ] Нет жёстко прописанных цветов и шрифтов в компонентах, всё идёт через токены.
- [ ] Корректно выглядит на мобильных экранах (нижний лист, поле набора не ломается при размере 38px).
- [ ] Существующая функциональность (режимы, языки, Tab, Backspace, Ctrl+Backspace, статистика, вкладка Profile) не сломана.
